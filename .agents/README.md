# Agent guidance

These instructions apply to the entire repository. Read the documents relevant
to the work before changing files or running commands:

- [`repository.md`](repository.md) is mandatory for every task. It describes the
  project, repository structure, and operational boundaries.
- [`styleguide.md`](styleguide.md) is mandatory before changing code,
  configuration, tests, or scripts.
- [`design.md`](design.md) is mandatory before changing interface behavior,
  styling, responsive layouts, or accessibility behavior.
- [`commands.md`](commands.md) is mandatory before running project commands. It
  records the canonical commands, required verification, and their side effects.

Instructions from the user take precedence over repository guidance.
